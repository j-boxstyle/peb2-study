# PEB2 Study Site — Principles of Economics and Business 2 (resit)

A single-page quiz site for revising **PEB2** (UvA) for the resit exam. Format: **40 MCQ**, four tracks (Digital Firm, Economics of Taxation, Moral Limits of Markets, Sustainability).

**Live:** https://j-boxstyle.github.io/peb2-study/

## Features
- 126 MCQs: the **Mock Exam (40, verbatim)** plus lecture/article concept and predicted questions.
- Filter by week, track, source (past-exam / textbook / predicted), and review modes (wrong / not-understood / unanswered).
- Randomised answer positions, Japanese explanations, and Opus 4.8 AI-prompt buttons (analysis / quiz / batch).
- Tabs: 📖 Textbook · 📋 Summary · ❓ Quiz · 📚 Glossary.

## Source policy
All content is derived **only** from UvA Canvas materials (lecture slides L1–L8, tutorials, the Mock Exam, and the prescribed articles). No web search, no other universities' materials, no student wiki. The copyrighted source PDFs are **not** included in this repository.
